# 自动运行步骤说明

当任务开启 **自动运行（auto_run）** 时，本镜像会按下列顺序执行：

1. **容器启动与换票** — 向任务云登记可达性，拉取任务详情与仓库凭证上下文。
2. **引导克隆** — 按任务关联仓库克隆到工作层，并准备功能参数环境。
3. **首条 Agent 指令** — 将任务标题与描述作为第一条 Trae 指令自动提交执行。
4. **完成后交付**（仅当首指令成功结束）— 同步 Git 身份 → 提交工作区变更 → 推送远端并创建 PR（若配置目标分支）。

> 说明：若自动运行关闭，或引导最终失败，则不会执行第 3、4 步。
> 若首次引导因仓库凭证未齐（409）中止，随后凭证恢复并完成克隆后，仍会执行第 3 步（及成功后的第 4 步）。
> 本文档路径固定为 `/app/autoRunStep.md`；镜像市场注册时会抽取本文件供容器未启动时预览。
